# 한 걸음

하루 3분, 일상을 수행으로. 20·30대 청년을 위한 생활수행·명상 웹앱입니다.
기획 근거: 「신대승 생활불교 수행론 기반 포교·출가 증대 기획서」 5장, 신대승네트워크 「신대승불교 생활수행론」(2026.9.26 수정본).

- 배포: https://hangeoleum.vercel.app (Vercel, 빌드 없는 정적 사이트)
- 개인 기록은 사용자의 브라우저(localStorage)에만 저장되며 서버로 보내지 않습니다.
- 출가 상담은 https://chulga-platform1.vercel.app 으로 연결됩니다.

## 파일 구성
| 파일 | 내용 |
| --- | --- |
| `index.html` | 앱 뼈대, 하단 탭 |
| `parts/*.html` | 탭별 화면(오늘·명상·여정·함께·출가) |
| `d1.js`~`d4.js` | 문구 데이터(10대 약속·경전 구절·명상·8주 과정·출가 이야기·FAQ) |
| `app.js` | 동작 로직 |
| `boot.js` | 화면과 스크립트를 순서대로 불러옴 |
| `style.css` | 디자인(라이트/다크) |
| `SPEC.md` | 개발 지시서 |

## 문구를 고치려면
`d1.js`~`d4.js`나 `parts/*.html`의 한글 문장을 고치고 커밋하면 Vercel이 자동으로 다시 배포합니다.

## 배포 연결
GitHub `main` 브랜치에 커밋하면 Vercel `hangeoleum` 프로젝트로 자동 배포됩니다(2026-10-06 연결).
